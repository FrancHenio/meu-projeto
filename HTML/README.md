# 🧠 Aprendizado de HTML com Mimo

Esse repositório contém minhas anotações, códigos de prática e aprendizados ao longo do curso de **HTML** no aplicativo [Mimo](https://getmimo.com/).  
É uma forma de reforçar o conhecimento e compartilhar o que venho aprendendo.

---

## 🚀 Tecnologias

- HTML5 (foco principal)
- Um pouquinho de CSS (em alguns exemplos)

---

## 📚 O que tem aqui?

- Explicações curtas sobre elementos HTML
- Exemplos práticos feitos por mim
- Mini-projetos de treino
- Comentários e observações pessoais

---

## 💡 O que eu aprendi até agora

- Como usar tags como `<h1>`, `<p>`, `<img>`, `<a>`, `<ul>`, `<table>`, etc.
- Estrutura básica de um documento HTML
- Como criar links, listas, imagens e tabelas
- Organização e indentação do código
- Primeiros passos com CSS inline
